# Farm archive design system

Use the tokens and component rules in [globals.css](src/app/globals.css). The page background is `--void` (#020202), panels use `--panel` (#1d1d1d), primary text uses `--ink` (#f1fec8), and interactive emphasis uses `--portal` (#99e1d9).

Use the existing Trebuchet MS stack, heavy compact headings and small uppercase labels for metadata. Reserve the large wordmark treatment for the opening scene. Keep the DN and edition legible at card size.

Reuse the archive card and dock styles for new catalog actions. Give icon controls accessible names, retain the portal-colored keyboard focus ring, and respect reduced motion. On a narrow screen, check the last card and its download actions with the fixed dock visible.
