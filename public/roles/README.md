# Role icons

Upload a square PNG here. Use the lowercase role name, replace each run of punctuation or spaces with a hyphen, and trim leading or trailing hyphens. Examples include `sinful-tech.png`, `farm-designer.png`, `1-22-before-gta-6.png`, and `infinity-125-plus.png`. Icons appear on the roles page after deployment.
Use `plus.png` for `+`, `bots-plus.png` for `Bots+`, and `infinity-125-plus.png` for `Infinity [125+]`.
